# Tuya Cloud setup

> [!NOTE]
> Those instructions may change anytime at Tuya's discretion.

- Pair your Tuya devices using Smart Life App or Tuya Smart App. Do not use a 'guest' account. 
- Create an account at Tuya Developer Platform: https://platform.tuya.com/
- Create a Cloud Project, select "Smart Home" on Industry and Development Method fields. 
  - On API Services, make sure that "IoT Core" and "Authorization Token Management" are enabled.
- Link Smart Life App or Tuya Smart App Account to your Cloud Project using "Devices" and "Link App Account" tabs.
  - Make sure "Automatic Link" is selected on Device Linking Method after scanning the QR code.
  - Double check if your paired devices appear under Devices tab.
- Copy your project Client ID and Client Secret and remember your set project location.
